# 🏡 SeeMyStay

A web application where users can explore places, add listings, upload images, and write reviews.

---

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- EJS
- Bootstrap
- Cloudinary

---

## ✨ Features
- User Authentication (Login / Register)
- Add, Edit, Delete Listings
- Image Upload (Cloudinary)
- Reviews & Ratings
- Responsive UI
